Install the free local ASR adapter with `py -3.13 -m pip install -r voice_service/requirements.txt`, then run `py -3.13 -m uvicorn voice_service.main:app --host 127.0.0.1 --port 8000`. Use Python 3.13 for this service; the currently installed Python 3.14 has a FastAPI compatibility issue. The service preloads the fast `tiny` model and uses greedy decoding for short Samadhan-Didi-style turns. Set `WHISPER_MODEL=base`, `small`, or `large-v3` when accuracy matters more than latency. For the full 22-language target, replace the Whisper loader with AI4Bharat IndicConformer.
